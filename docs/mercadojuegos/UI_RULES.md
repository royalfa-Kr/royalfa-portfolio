# UI Rules - MercadoJuegos

## Objetivo
Mantener consistencia visual y evitar rediseños no aprobados.

## Principios visuales
- interfaz limpia
- legibilidad primero
- navegación simple
- formularios claros
- responsive design
- consistencia con el ecosistema visual del sitio principal

## Restricciones
- no rediseñar layouts aprobados sin autorización
- no cambiar estilos globales sin autorización
- no introducir nuevas librerías UI sin aprobación
- no reemplazar componentes existentes si pueden extenderse
- no modificar otras secciones del sitio para acomodar MercadoJuegos sin autorización

## UX del MVP
- acceso simple a publicar juego
- búsqueda visible
- cards de publicaciones fáciles de escanear
- detalle de publicación con CTA claro
- mensajes fáciles de ubicar
- wishlist simple y útil
- estados visibles de disponibilidad
